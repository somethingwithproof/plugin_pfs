# دليل المشغّل

كيفية تثبيت الملحق وتشغيله وترقيته ونسخه احتياطيًا وإزالته، ومعنى رسومه وقيمه. إعداد العقد في [node-setup.md](node-setup.md)، والتنبيه باستخدام Thold وMaint في [alerting.md](alerting.md).

الحالة: شيفرة المرحلة 1 مكتملة ولم تعمل إلا مع خرج عقد اختباري في Cacti مؤقت. لم يرد تقرير تجربة على نظام Lustre حقيقي بعد ([#57](https://github.com/somethingwithproof/plugin_pfs/issues/57))؛ اعتبر كل رقم أدناه نتيجة عينات اختبار حتى يرد ذلك.

<a id="requirements"></a>
## المتطلبات

| المكوّن | المتطلب |
|---|---|
| Cacti | 1.2.31 أو أحدث، دون ترقيعات للنواة |
| PHP | 8.2 أو أحدث على كل مضيف يشغّل الويب أو مستطلعًا. على 8.0 أو 8.1 يرفض الملحق التفعيل ويستمر Cacti بالعمل |
| Lustre | خوادم يُوصل إليها عبر SSH بسكربت القراءة المفروض؛ الإصدارات المفحوصة من المصدر 2.15.8 و2.16.1 و2.17.0 |
| مضيف المستطلع | عميل `ssh` ومفتاح خاص للقارئ وملف مضيفين معروفين |

<a id="install"></a>
## التثبيت

1. فك الإصدار ليكون دليل الملحق `<path_cacti>/plugins/pfs`. يجب تسميته `pfs`؛ يُفك أرشيف GitHub باسم `plugin_pfs-<version>` ويجب إعادة تسميته.
2. في Cacti افتح الإعداد ثم الملحقات وثبّت أنظمة الملفات المتوازية وفعّلها. ينشئ التثبيت الجداول ويسجّل الخطافات وثلاثة مجالات صلاحيات ويستورد قوالب الأجهزة والبيانات والرسوم وينسخ ملفي استعلام البيانات إلى Cacti (القسم التالي).
3. امنح المجالات المطلوبة في إدارة المستخدمين: **Parallel Filesystem View** للجرد والحداثة، و**Parallel Filesystem Operator** لصفحة العمليات وإقرارات الفرز الشخصية، و**Parallel Filesystem Admin** للسجل والصحة. يرث Admin وصول Operator ويرث Operator وصول View في كل طلب دون إضافة منح دائمة. تتبع المجالات الثلاثة صلاحيات أجهزة Cacti.
4. افتح وحدة التحكم ثم صحة أنظمة الملفات المتوازية. يحدد كل تحذير ما يجب إصلاحه. عادةً يظهر غياب مفتاح SSH وملف المضيفين المعروفين حتى إكمال الخطوات التالية.
5. جهّز العقد والمستطلع كما في [node-setup.md](node-setup.md).
6. في إدارة أنظمة الملفات المتوازية اسمح بشبكات كل مستطلع، وأضف نظام الملفات ثم عقده (نقطة النهاية والمنفذ واسم الدخول والدور). لا تُحفظ عقدة تُحل نقطة نهايتها خارج الشبكات المسموحة.
7. انتظر فترة استطلاع. يعمل القارئ من خطاف Cacti `poller_bottom` على كل مستطلع ويملأ الجرد. راجع الأهداف المقترحة في صفحة النظام؛ يخرج الهدف المتجاهل من الاستعلامات والملخص.
8. أنشئ جهاز النظام من الإدارة أو اربطه بجهاز موجود. يسرد الملحق ما سيضيفه قبل إضافته: الجهاز والاستعلامين وخمسة رسوم عامة. تُنشأ رسوم الأهداف عند الطلب من صفحة الرسوم الجديدة في Cacti.

<a id="data-query-files"></a>
### ملفات استعلام البيانات

لا يقرأ Cacti ملف XML لاستعلام البيانات إلا داخل `<path_cacti>/resource`، لذا ينسخ التثبيت `resource/script_server/pfs_osts.xml` و`pfs_mdts.xml` من الملحق إلى `<path_cacti>/resource/script_server/`. يرفض رابطًا رمزيًا في أي وجهة ويكتب كل ملف عبر ملف مؤقت في الدليل نفسه. لا يسجّل SHA-256 إلا لملف كتبه: الملف الموجود بالمحتوى نفسه، مثل نسخة يدوية بالخطوات أدناه، يُستخدم لكنه يظل ملكك وتتركه الإزالة. لا يستبدل التثبيت ملفًا لم يكتبه أو تغير لاحقًا، ولا تزيل الإزالة إلا الملفات التي كتبها ولم تتغير.

إذا لم يستطع مستخدم الويب الكتابة إلى الدليل، تعرض الصحة ذلك ولا تستطيع الاستعلامات سرد الأهداف. انسخ الملفات مرة بحساب مخوّل، مع إبقائها مقروءة لمستخدمي الويب والمستطلع:

```sh
cd <path_cacti>
install -m 0644 plugins/pfs/resource/script_server/pfs_osts.xml resource/script_server/
install -m 0644 plugins/pfs/resource/script_server/pfs_mdts.xml resource/script_server/
```

ثم استخدم **تثبيت القوالب مجددًا** في الصحة. يزول التحذير حين تطابق النسختان نسختي الملحق. لأنهما ملكك، لا يحدّثهما الملحق ولا يزيلهما: كرر النسخ بعد ترقية تغيّر أي ملف (تحذر الصحة عند الاختلاف)، وأزلهما بنفسك بعد الإزالة.

<a id="what-the-graphs-and-values-mean"></a>
## معنى الرسوم والقيم

كل نظام ملفات جهاز Cacti واحد. أهدافه OST وMDT فهارس لاستعلامي خادم سكربت. تأتي كل قيمة من ذاكرة القارئ المؤقتة؛ لا يتصل أي رسم أو صفحة أو مصدر بيانات بعقدة.

| الرسم | القيم | مجهولة عندما |
|---|---|---|
| الامتلاء (عام) | أعلى ومتوسط وأدنى نسبة استخدام OST وأعلى نسبة استخدام inodes للأهداف؛ وتظهر أسفل هذا الرسم أعداد الأهداف الكلية والمفقودة وغير السليمة والثواني منذ أقدم ملاحظة وراء الملخص | نسب السعة: لا يملك أي هدف قراءة حديثة لذلك المقياس؛ عمر البيانات: لم يُرصد قط |
| عدم التوازن (عام) | الفارق بين أعلى وأدنى نسبة استخدام OST | لا يملك أي OST قراءة سعة حديثة |
| السعة (عام) | إجمالي الكيلوبايت والمتاح للنظام | يفقد أي OST أو يتقادم، فيكون المجموع جزئيًا |
| الإنتاجية (عام) | بايتات القراءة والكتابة في الثانية للنظام ومقاييس معدل القراءة والكتابة للتنبيه (تظهر أسفل الرسم) | يفقد OST أو يتقادم أو يكون غير سليم دون عداده أو يُعاد ضبطه خلال الفترة؛ وتكون مقاييس المعدل مجهولة أيضًا لاستطلاعين أو ثلاثة بعد إعادة الضبط |
| البيانات الوصفية (عام) | عمليات البيانات الوصفية في الثانية، جميع العمليات المسموحة معًا، ومقياس معدل العمليات للتنبيه | يفقد MDT أو يتقادم أو يُعاد ضبطه خلال الفترة؛ ويكون مقياس المعدل مجهولًا أيضًا لاستطلاعين أو ثلاثة بعد إعادة الضبط |
| سعة OST وInodes وإنتاجيته (لكل هدف) | المستخدم والمتاح وinodes وبايتات القراءة والكتابة والعمليات في الثانية | الهدف مفقود أو قديم أو لم تطبع العقدة القيمة |
| سعة MDT وعملياته (لكل هدف) | المستخدم والمتاح وinodes والعمليات في الثانية بحسب العملية | كذلك |

قواعد الجدول:

- **نسبة الاستخدام** تتبع `lfs df`: المستخدم مقسومًا على المستخدم زائد المتاح، مع التقريب للأعلى.
- **المجهول فجوة لا صفر.** الهدف المفقود والقراءة الفاشلة والقيمة غير المطبوعة تظهر فجوة.
- تُخزّن **العدادات** خامًا كـDERIVE بحد أدنى 0. تجعل إعادة الضبط (انخفاض، أو تغير `start_time`، أو رد عقدة مختلفة بعد تجاوز الفشل، أو قيمة سابقة مجهولة) فترة واحدة فقط مجهولة.
- **الحداثة.** القيمة حديثة حتى فترة ونصف، ومتأخرة حتى ثلاث، وقديمة بعدها. تُقدّم قيم gauge وهي حديثة أو متأخرة؛ أما العدادات ومقاييس المعدل في الملخص فتُقدّم وهي حديثة فقط، فتكون القراءة المفقودة فجوة لا خطًا مسطحًا يتبعه معدل مضاعف.
- **الأهداف الخاملة.** لا يطبع Lustre عدادًا لم يعدّ شيئًا منذ بدايته. تحسبه مجاميع النظام صفرًا لهدف موجود وفي الخدمة وبلّغ قيمه الأخرى في القراءة نفسها؛ يظل رسم الهدف فجوة ([ADR 0013](../../../decisions/0013-absent-counter-lines-count-as-zero-in-sums.md)).
- **تغير مجموعة الأهداف.** عند دخول هدف إلى مجموع أو خروجه، يكون المجموع مجهولًا لاستطلاع واحد كي لا يُرسم تاريخه كله كفترة واحدة.
- تحتفظ **الأهداف المفقودة** بفهرسها ومصادرها وتاريخها حتى يتجاهلها مسؤول في السجل.

<a id="upgrade"></a>
## الترقية

1. خذ نسخة احتياطية أولًا (أدناه).
2. استبدل دليل `plugins/pfs` بالإصدار الجديد مع إبقاء الاسم.
3. افتح الإعداد ثم الملحقات. يعرض Cacti الإصدار الجديد ويحدّث الملحق مخططه وخطافاته ومجالاته وقوالبه وملفات الاستعلام عند تحميل إعداد Cacti التالي (ويحدث بفتح الملحقات). تكتمل الترقية المنقطعة عند التحميل التالي. لا يعمل القارئ إذا تأخر المخطط، ويسجّل ضرورة إكمال الترقية.
4. إن كنت ترقي من إصدار تمهيدي يسبق مقاييس المعدل، فاحفظ ما تحتاجه من تاريخ رسمي الإنتاجية والبيانات الوصفية، ثم احذف هذين الرسمين العامين وأعد إنشاءهما. لا تحتوي ملفات RRD الحالية على مصادر بيانات المعدل الجديدة.
5. افحص الصحة وسجل Cacti. تُبلّغ مشكلات القالب أو ملف الاستعلام ولا تُتخطى بصمت.

يُرفض الرجوع إلى إصدار أقدم إذا كان مخطط قاعدة البيانات أحدث من الشيفرة؛ استعد نسخة ما قبل الترقية بدلًا من ذلك.

<a id="back-up-and-restore"></a>
## النسخ الاحتياطي والاستعادة

انسخ العناصر التالية معًا في اللحظة نفسها:

| العنصر | الموضع |
|---|---|
| جداول الملحق | كل جدول `plugin_pfs_*` في قاعدة Cacti (`mysqldump cacti $(mysql -N -e "SHOW TABLES LIKE 'plugin\_pfs\_%'" cacti)`)، أو قاعدة Cacti كاملةً |
| كائنات Cacti | قاعدة البيانات: أجهزة الأنظمة ومصادرها ورسومها والقوالب وإعدادات الملحق في `settings` (`pfs_*`) |
| ملفات RRD | `<path_cacti>/rra` أو دليل RRD لديك |
| وصول العقد | على كل مستطلع ملف مفتاح SSH والمضيفين المعروفين من إعدادات الملحق. على كل عقدة حساب القارئ وسطر `authorized_keys` و`/usr/local/libexec/pfs-read.sh` |
| نسخ الاستعلام | `<path_cacti>/resource/script_server/pfs_osts.xml` و`pfs_mdts.xml` إذا نسختهما يدويًا |

للاستعادة أوقف المستطلعات، واستعد قاعدة البيانات ودليل RRD من النسخة نفسها، واستعد المفتاح وملف المضيفين المعروفين، ثم ابدأ المستطلعات. يستأنف القارئ في التشغيل التالي دون تكرار مصادر البيانات: يُطابق الجهاز ومصادره وملفات RRD بمعرّفاتها ومساراتها المخزنة. يرسم أول استطلاع بعد الاستعادة فترة عداد مجهولة واحدة لأن القارئ لا يثق بمعدل عبر الفجوة. إذا كان المخطط المستعاد أقدم من الشيفرة، يكتشفه الملحق ويرقّيه كما سبق. تُختبر الاستعادة بواسطة `tests/bin/restore-flow.php`.

<a id="uninstall"></a>
## الإزالة

1. اختياري: صدّر السجل من إدارة أنظمة الملفات المتوازية.
2. عطّل الملحق ثم أزله في الإعداد ثم الملحقات.
3. تزيل العملية الخطافات والمجالات ونسخ ملفات الاستعلام التي كتبها الملحق ولم تتغير. يوقف حذف `poller_bottom` القارئ، فلا تُجمع قيم العقد بعد الإزالة: تحفظ الرسوم تاريخها لكن تتوقف عن التحديث وتصبح قيمها الأحدث مجهولة. تبقى القوالب المستوردة في Cacti كأي قالب مستورد. مع تحديد **الاحتفاظ بجداول الملحق عند الإزالة** (الافتراضي) تبقى الجداول؛ ألغِه لحذفها.
   - **الأجهزة.** يبقى كل جهاز افتراضيًا مع مصادر بياناته ورسومه. حدد **حذف الأجهزة التي أنشأها هذا الملحق عند الإزالة** في الإعداد ثم الإعدادات ثم أنظمة الملفات المتوازية (معطّل افتراضيًا) لحذف الأجهزة التي أنشأها الملحق من صفحة الإدارة عبر وظيفة حذف الأجهزة في Cacti: تُحذف معها رسومها ومصادر بياناتها، ولا تُحذف ملفات RRD إلا إذا نص إعداد تنظيف RRD في Cacti على ذلك. يسجّل الملحق كل جهاز ينشئه، صفًا لكل جهاز في `plugin_pfs_created_devices`؛ ولا يدخل الجهاز الموجود الذي ربطته بنظام ملفات هذا السجل مطلقًا ويبقى دائمًا مع الاستعلامات والرسوم العامة التي أضافها الربط. لا يحتفظ نظام الملفات بربط إلى جهاز حُذف، فلا تشير الجداول المحفوظة إلى جهاز محذوف. تحتفظ الإزالة التي تحذف جداول الملحق بجدول `plugin_pfs_created_devices` ما دام يسرد جهازًا لا يزال في Cacti، كي تتمكن إعادة التثبيت والإزالة لاحقًا من حذفه؛ احذف هذا الجدول يدويًا إن كنت ستحتفظ بتلك الأجهزة نهائيًا. إزالة الأجهزة والمصادر والرسوم وملفات RRD التي أنشأتها بنفسك مسؤوليتك.
4. على كل عقدة أزل سطر `authorized_keys` للقارئ والسكربت والحساب. لا تتصل الإزالة بعقد التخزين مطلقًا.

<a id="troubleshooting"></a>
## استكشاف الأخطاء وإصلاحها

ابدأ بالصحة؛ تحدد العقدة والمستطلع والسبب. ثم سجل Cacti مرشّحًا على `PFS`.

| العَرَض | السبب والإصلاح |
|---|---|
| تعرض عقدة «مفتاح المضيف غير موجود في الملف المعروف أو تغير» | أضف المفتاح أو صححه تحت اسم نقطة النهاية المسجّل حرفيًا. تحقق من المفتاح المتغير بقناة مستقلة قبل الثقة به؛ لا يقبله القارئ بنفسه |
| «أجابت دون علامات سكربت القراءة الثابت» | المفتاح غير مقيد بالأمر المفروض أو الأمر ليس `pfs-read.sh`. أصلح سطر `authorized_keys` |
| «طبعت N معاملات لا يقرأها الملحق» | تشغّل العقدة غير السكربت المرفق. أعد تثبيت `node/pfs-read.sh` |
| «تُحل خارج الشبكات المسموحة» | اسمح بالشبكة للمستطلع في الإدارة أو صحّح نقطة النهاية |
| قراءة عقدة مسجلة فاشلة أو جزئية | تعذر الوصول أو انتهاء مهلة أو إجابة أكبر من **أقصى استجابة**. تحتفظ الأهداف بآخر قيمها حتى التقادم ثم تصبح مجهولة |
| «لم يكمل قارئ المستطلع N تشغيلًا» | لا يشغّل المستطلع `poller_bottom` أو PHP أقل من 8.2 أو **مسار ملف PHP التنفيذي** فارغ في Cacti. يحدد السجل السبب |
| الاستعلامات لا تسرد أهدافًا | نسخ الملفات مفقودة أو مختلفة (راجع ملفات الاستعلام)، أو لم يكمل القارئ قراءة بعد |
| عدادات الهدف فجوة دائمًا | لا يقرأ الحساب ملف OST `stats`. على Lustre 2.17 هو في debugfs ([node-setup.md](node-setup.md)) |
| إنتاجية النظام فجوة لكن إنتاجية الأهداف تُرسم | هدف مفقود أو قديم أو غير سليم أو أُعيد ضبطه للتو؛ تبيّن أعداد المفقود وغير السليم في رسم الامتلاء الحالة |
| الرسوم العامة منشأة لكنها فارغة | يستطلع الجهاز مستطلع غير الذي يقرأ عقده؛ تحذر الصحة من الاختلاف |
| يظهر `Plugin 'thold': Uncaught TypeError` ويُعطّل Thold | رأت عتبة عداد فترة مجهولة؛ احذف العتبة وأعد تفعيل Thold في الملحقات وراجع [alerting.md](alerting.md#counters-and-thold-182) |
